# Stage 4 — Content Model

Status: **IN PROGRESS — not yet approved by Controller**.

The stage will define one complete grade-6 mathematics module:
- subject/topic/skill schema;
- prerequisite graph;
- diagnostic items;
- problem schema and difficulty;
- hints and fading;
- error/misconception diagnostics;
- deterministic answer verification;
- evidence emitted to the knowledge model;
- review rules;
- bridge from curriculum mastery to transfer and olympiad-style problems.

No Stage 5 implementation starts before Controller approval.
