# Mathematics content package

Status: Stage 4 reference content; not production-approved until Controller approves Stage 4.

The first MVP module is grade-6 common fractions. Content is data-first and must remain separable from the application core.

## Reference slice

`fractions/add_unlike/` demonstrates the complete pedagogical cycle for **adding fractions with unlike denominators**:
diagnostic → misconception/prerequisite probe → explanation → worked example → guided/fading practice → independent evidence → transfer → review.

Machine-readable schemas will be enforced by content validation in Stage 5.
